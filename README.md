# Заметки и задачи — тестовое задание для Авито

Android-приложение для заметок и списка дел. В заметки можно добавлять фотографии и диктовать текст, а задачи можно создавать вручную или голосом.

**Стек:** Kotlin, Jetpack Compose, Navigation Compose, ViewModel, Room, Coroutines, Flow, Retrofit, OkHttp, Gson.

## Что реализовано

- **Заметки:** создание, редактирование и удаление, добавление изображений из файлов или камеры.
- **Задачи:** создание, отметка выполнения и фильтрация по статусу. Выполненные задачи отображаются ниже активных.
- **Поиск и сортировка:** поиск по названию и сортировка по дате.
- **Голосовой ввод:** Android `SpeechRecognizer` распознаёт речь. При диктовке заметки текст добавляется в редактор, а при создании задачи GigaChat преобразует распознанную фразу в короткий заголовок.
- **Настройки:** системная, светлая и тёмная темы, выбор акцентного цвета, сброс настроек и просмотр баланса токенов GigaChat.

## Как устроен проект

Приложение состоит из одного модуля `app` и трёх слоёв. В `domain` находятся модели и интерфейсы репозиториев. В `data` — база Room, реализации репозиториев, файловое хранилище, настройки и клиенты внешнего API. В `presentation` — экраны Compose, навигация и ViewModel. Зависимости собираются в `AppContainer` и передаются в ViewModel через фабрики.

`RoomNoteRepository` и `RoomTaskRepository` отвечают за сохранение заметок и задач. Экраны получают обновления через `Flow`. Изображения хранятся во внутренней папке приложения, в Room записываются пути к ним, а настройки темы сохраняются в `SharedPreferences`.

## Запуск

Откройте проект в Android Studio и синхронизируйте Gradle. Для сборки используются Android SDK 37 и JDK 25. Запустите модуль `app` на Android 7.0 (API 24) или новее.

Для функций GigaChat скопируйте `secrets.properties.example` в `secrets.properties` и задайте `GIGACHAT_AUTH_KEY`, `GIGACHAT_SCOPE` и `GIGACHAT_MODEL`. Для диктовки предоставьте приложению разрешение на микрофон.

В проекте есть unit-тесты и инструментальные тесты экранов, хранения данных и голосового ввода. Команда для запуска unit-тестов: `./gradlew :app:testDebugUnitTest`.
