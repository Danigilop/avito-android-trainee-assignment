# Заметки и задачи

Тестовое Android-приложение для стажировки в Авито.

## Возможности

- Заметки: создание, редактирование, удаление, изображения из файлов и камеры.
- Задачи: создание прямо в списке, отметка выполнения и фильтр статуса.
- Поиск по названию и сортировка по дате. Выполненные задачи находятся ниже активных.
- Голосовой ввод текста заметки и создание задачи с обработкой текста через GigaChat.
- Системная, светлая и тёмная темы, выбор основного цвета и сброс настроек.
- Просмотр баланса токенов GigaChat.

Заметки и задачи сохраняются в Room, изображения — во внутренней папке приложения, настройки — в SharedPreferences. Списки автоматически обновляются через Flow.

## Технологии и структура

Kotlin, Jetpack Compose, Navigation Compose, MVVM, Room, Coroutines, Flow, Retrofit, OkHttp, Gson. Один модуль `app` с разделением на слои:

- `domain` — модели и интерфейсы репозиториев;
- `data` — база данных, файлы, настройки и сетевые запросы;
- `presentation` — экраны, ViewModel, навигация и тема.

## Запуск

1. Откройте корневую папку проекта в Android Studio.
2. Для текущей конфигурации нужны Android SDK 37 и JDK 25 для Gradle. Дождитесь синхронизации и загрузки зависимостей.
3. Для баланса и голосовых задач скопируйте `secrets.properties.example` в `secrets.properties`, укажите ключ GigaChat, scope и доступную вашему аккаунту модель.
4. Запустите конфигурацию `app` на устройстве или эмуляторе с Android 7.0 (API 24) или новее.



## Ограничения

- Речь распознаётся через Android SpeechRecognizer. SaluteSpeech не используется, новые подключения SaluteSpeech закрыты с 15 июля 2026 года.
